# MusicDeck: 의도 (2026-10-18 확정)

- **결과물:** 데스크톱에 늘 떠 있는 작은 음악 기기. 재생 출처(크롬·사파리의 유튜브 탭 또는 애플뮤직)와 곡 제목을 보여준다.
- **조작:** 다이얼 두 개(맥 전체 볼륨, 노래 볼륨), 재생·멈춤과 다음 곡 버튼. 출처를 누르면 해당 탭이나 앱으로 이동한다.
- **느낌:** 틴에이지 엔지니어링 같은 모던한 디자인. 다이얼을 돌리면 딸깍 소리가 나는 등 소리와 손맛이 있다.
- **사용자·목적:** 본인 한 명이 매일 쓰는 도구. 학습용이 아니므로 Claude가 직접 만든다.
- **성공 기준:** 출처를 찾거나 볼륨을 바꿀 때 메뉴바나 탭을 뒤지지 않고 이 기기만 보고 만지면 된다.
- **제약:** 시스템 Now Playing 정보는 macOS 15.4부터 막혀 있어서, 크롬·사파리·애플뮤직에 AppleScript로 직접 묻는다. 크롬과 사파리에서 "Apple Events의 JavaScript 허용"을 켜야 한다.
- **범위 밖:** macOS 정식 위젯(WidgetKit은 소리와 다이얼 조작이 안 됨), 유튜브·애플뮤직 이외의 소스, 제어 센터의 다른 기능.
